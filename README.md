Смешанный плейлист iptv Руские каналы тв  в формате m3u.

Ссылка: https://raw.githubusercontent.com/artem-art998/IPTVru/refs/heads/main/iptv126.m3u

Ссылка: https://clck.ru/3SiP7t

Для Андроид ТВ.

Работает на проигрывателе:

Wuffy Player (версия : 3.5.7 arm64-v8a) apk. (Андроид от 5.0 до 16.0).

Wiseplay (версия: 8.1.34-tv) apk. (Андроид от 5.0 до 16.0).

(На других проигрывателях может не работать).

Программу для IPTV можно использовать любую:  Lazy IPTV, IPTV,  (Televizo со встроиным проигрывателем. версия 1.9.3.1 (для Андроид 5.0 до 16.0) работают 90% каналов) или любую другую для удобства.

(Плейлист работает только на России, в других странах работоспособность не проверена).
